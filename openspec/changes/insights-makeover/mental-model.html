Change delta

insights-makeover

plaid-importer takes on the Media Insights design system and uses it to show what the app already records: trends, health, routing, and the week ahead.

Shape of the change

Presentation plus read-only insight queries. Still Fastify + Eta + vanilla JS. No sync, scheduler, Plaid, Actual, or auth behavior changes; no migrations; no new runtime dependency.

Borrowed from Media Insights

  • Token sheet (light + dark), Playfair / DM Sans / DM Mono — fonts vendored, not CDN
  • Page intro: eyebrow, headline, one-line lede, actions on the right
  • Hero card with one big figure and pills; metric grid; panels
  • Bar list with value + share as text and hover/focus tooltip
  • Calm row lists, icon actions on hover/focus, visible on touch
  • Notices for banners and results; pre-paint theme script

New to this app

  • Column chart (imports per day) built from flex columns + hidden table
  • Freshness chips: fresh · stale · old · never · relink
  • Rate-limit meter per connection (only when a ceiling is set)
  • Routing rows: bank account → Actual account → pending
  • Coverage meter: N of M syncable accounts routed
  • Week strip of upcoming scheduled runs
